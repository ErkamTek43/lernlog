# Lern-Log

Gebaute Fassung einer Lern-Log-Web-App, bereitgestellt über GitHub Pages.

Die App ist eine installierbare Progressive Web App (PWA). Sie läuft nach dem ersten Laden offline, alle Daten bleiben lokal im Browser. Es gibt keinen Server und kein Login.

Dieses Repository enthält nur die fertig gebauten Dateien. Der Quellcode wird separat gepflegt.

**Technik:** TypeScript, React, Vite, IndexedDB (Dexie)
